# Task 2: Phishing Email Detection & Awareness System

## Overview
This project focuses on identifying common phishing indicators in email messages and educating users about email safety.

## Objectives
- Identify common phishing warning signs.
- Classify email examples as Safe, Suspicious, or Phishing indicators present.
- Explain safe practices for handling suspicious emails.
- Promote phishing awareness and prevention.

## Project Contents
- `email_samples/` — Three fictional email samples created for educational purposes.
- `report/` — Phishing Detection and Awareness Report in PDF format.
- `evidence/` — Project screenshots and supporting evidence, if available.

## Tools
- Google Docs
- Notepad
- Google Admin Toolbox Messageheader (reviewed; no actual email header analysis was performed)

## Important Note
The email examples are fictional and intended for cybersecurity awareness training. The classifications are preliminary and based only on the supplied text. No real sender addresses, email headers, or live domains were verified.
